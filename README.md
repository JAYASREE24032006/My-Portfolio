# My Portfolio

This repository contains my personal portfolio website, including the HTML, CSS, JavaScript, and supporting assets used to showcase my skills, projects, and certifications.

## Overview

- `index.html` — Main portfolio landing page.
- `style.css` — Styling for the portfolio website.
- `script.js` — Frontend behavior and interactive features.
- `images/` — Visual assets used on the website.
- `Jayasree Certificate/` — Collection of certification files and PDFs.
- `scratch/` — Helper scripts for processing certificate data and analysis.

## Features

- Responsive portfolio website layout
- Project and certification showcase
- Certificate extraction and verification scripts

## How to use

1. Open `index.html` in a browser to view the portfolio site.
2. Edit the page content or styling in `index.html` and `style.css`.
3. Update or extend interactive features using `script.js`.

## Notes

- This repository includes sample certifications and data files used for analysis.
- The `scratch/` folder contains Python scripts for data extraction and verification.
